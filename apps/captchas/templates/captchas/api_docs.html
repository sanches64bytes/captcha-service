API de resolução de CAPTCHAs

Crie tarefas, acompanhe o processamento e receba soluções em ambientes autorizados.

Sua chave possui {{ key_threads }} thread(s). Ao atingir o limite, novas tarefas retornam HTTP 429 e não entram em fila.

Criar uma tarefa

POST/api/v1/tasks/

curl --request POST 'https://api.exemplo.com/api/v1/tasks/' \
  --header 'X-API-Key: <sua-chave>' \
  --header 'Content-Type: application/json' \
  --data '{
    "captcha_type": "recaptcha_v2",
    "data": {"googlekey": "<site-key>", "pageurl": "https://seu-sistema.example/pagina"}
  }'

Resposta imediata: 202 Accepted.

{"task_id":"4dd69e6c-781b-49ba-b59d-f3201507121f","status":"processing"}

Consultar uma tarefa

GET/api/v1/tasks/{task_id}/

A API apresenta processing desde a aceitação. O estado interno de espera do worker não é exposto.

{"task_id":"4dd69e6c-781b-49ba-b59d-f3201507121f","status":"completed","result":{"solution":"..."}}

Polling recomendado

Consulte a cada 3 a 5 segundos. Continue enquanto o status for processing e encerre em completed ou failed. Defina também um timeout no seu cliente.

criar tarefa → guardar task_id → aguardar 5s → consultar
                         ├─ processing: repetir
                         ├─ completed: usar result
                         └─ failed: tratar error

Payloads

Normal Captcha
{"captcha_type":"normal","data":{"body":"<base64>","content_type":"image/png","filename":"captcha.png","numeric":0,"regsense":0}}
Grid Image
{"captcha_type":"grid","data":{"body":"<base64>","content_type":"image/png","grid_size":"3x3","img_type":"recaptcha","instructions":"bicycles"}}
reCAPTCHA v2, Invisible e Callback
{"captcha_type":"recaptcha_v2","data":{"googlekey":"<site-key>","pageurl":"https://seu-sistema.example/pagina"}}

Use o mesmo payload alterando captcha_type para recaptcha_v2_invisible ou recaptcha_v2_callback.

reCAPTCHA v2 Enterprise
{"captcha_type":"recaptcha_v2_enterprise","data":{"googlekey":"<site-key>","pageurl":"https://seu-sistema.example/pagina","action":"login"}}
reCAPTCHA v3 e Enterprise
{"captcha_type":"recaptcha_v3","data":{"googlekey":"<site-key>","pageurl":"https://seu-sistema.example/pagina","action":"login"}}

Use recaptcha_v3_enterprise para a variante Enterprise.

GeeTest v3
{"captcha_type":"geetest_v3","data":{"gt":"<gt>","challenge":"<challenge-atual>","pageurl":"https://seu-sistema.example/pagina","api_server":"<opcional>"}}
Turnstile
{"captcha_type":"turnstile","data":{"sitekey":"<site-key>","pageurl":"https://seu-sistema.example/pagina"}}
Cloudflare Challenge
{"captcha_type":"cloudflare_challenge","data":{"pageurl":"https://seu-sistema.example/pagina","proxy":"<opcional>","proxytype":"HTTP","user_agent":"<opcional>"}}
BLS Captcha
{"captcha_type":"bls","data":{"instructions":"664","images":["<data-uri-1>","<data-uri-2>","<data-uri-3>","<data-uri-4>","<data-uri-5>","<data-uri-6>","<data-uri-7>","<data-uri-8>","<data-uri-9>"]}}
CaptchaFox
{"captcha_type":"captchafox","data":{"sitekey":"<site-key>","pageurl":"https://seu-sistema.example/pagina","proxy":"<opcional>","proxytype":"HTTP"}}
Friendly Captcha
{"captcha_type":"friendly_captcha","data":{"sitekey":"<site-key>","pageurl":"https://seu-sistema.example/pagina"}}
Lemin
{"captcha_type":"lemin","data":{"captcha_id":"<captcha-id>","pageurl":"https://seu-sistema.example/pagina","div_id":"<opcional>"}}

Imagens devem ser JPG/JPEG, PNG ou GIF, entre 100 bytes e 100 KB. Grid e BLS retornam listas de posições; GeeTest retorna challenge, validate e seccode.

Respostas importantes

HTTPSignificado
401Chave ausente, inválida ou expirada.
404Tarefa inexistente, expirada ou de outra chave.
422Payload inválido.
429Limite de threads atingido.
503Fila indisponível.

Formato de falha

{"task_id":"...","status":"failed","error":{"code":"captchaai_unsolvable","message":"..."}}

Não repita automaticamente erros de configuração. Para falhas temporárias, use poucas tentativas com espera progressiva.

Tarefas permanecem disponíveis por aproximadamente 30 minutos. Nunca registre chaves, imagens ou tokens em logs.
